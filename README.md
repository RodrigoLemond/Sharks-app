# Sharks App

## Controle Financeiro para Motoristas de Aplicativo

Sharks App é um aplicativo Android nativo destinado a motoristas de aplicativos (Uber, 99, iFood, etc.) para ajudar no controle financeiro, permitindo o registro de ganhos, despesas e acompanhar indicadores de rentabilidade!

### 🎯 Funcionalidades Principais

- Registro de corridas com valores, quilometragem, tempo e gorjetas.
- Cadastro de despesas como combustível, manutenção, alimentação e mais.
- Dashboard com cálculo de lucro por viagem e por quilômetro.
- Sistema de metas financeiras personalizáveis.
- Relatórios detalhados com gráficos e exportação em PDF.

### 🔧 Tecnologias Utilizadas

- **Linguagem:** Kotlin
- **UI Framework:** Jetpack Compose
- **Persistência:** Room Database
- **Arquitetura:** MVVM
- **Design:** Material Design 3
